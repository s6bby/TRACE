# APA 7 Formatting Guide for the Emerita Award Essay

## Important Note

This application essay is not a class paper, so strict APA structure is not always necessary unless the award instructions specifically require it. The safest approach is:

- use APA-style page formatting
- keep the essay professionally presented
- do not add unnecessary sections such as an abstract or running head unless requested

## Recommended Format

Use the following:

- font: `Times New Roman`, 12 pt
- spacing: double-spaced throughout
- margins: 1 inch on all sides
- alignment: left-aligned body text
- paragraph indentation: first line of each paragraph indented 0.5 inch
- page numbers: top right corner

## Title Page

For this kind of submission, use a simple title page rather than a classroom-style APA student paper page with course and instructor information.

Recommended title page content, centered and double-spaced:

**Evaluating Claim-Level Reliability in Large Language Model Interpretation of Special Education Documents**

Sebastian Andrades  
Washington State University Vancouver  
Emerita/Emeritus Society Undergraduate Research Award  
March 30, 2026

## First Page of Essay

Start the body on page 2.

At the top of page 2:

- place the title in bold, centered
- begin the essay on the next double-spaced line
- do not add the heading `Introduction`

## Headings

For this application, you likely do not need formal APA section headings unless the essay becomes highly structured. A plain essay is usually stronger here.

If you do want headings, keep them minimal:

- `Research Problem`
- `Methods`
- `Results and Significance`
- `Individual Contribution`

## Citations

Only include APA in-text citations and a reference page if you actually cite outside sources.

If the essay is based on your own project and does not cite articles, do not add a references page just to look formal.

## File Preparation

For submission:

1. write and revise in Google Docs or Word
2. apply the formatting above
3. export as PDF
4. check that the PDF preserves page numbers, spacing, and margins

## Clean Submission Template

Use this structure:

### Page 1

Title page

### Page 2 onward

Bold centered title  
Essay body

## Final Advice

For this award, strong content matters more than performing APA mechanically. Reviewers will care more about:

- clarity
- specificity
- evidence of individual contribution
- significance of the work

APA formatting should make the essay look professional, but it should not make the essay read like a class assignment.
