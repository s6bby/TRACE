# TRACE-ED Meeting Materials

This folder is the clean meeting packet for the current TRACE-ED prototype.

Files:

- `results_summary.md` has the current AWS Bedrock run results.
- `development_notes.md` explains what changed in the pipeline and what still needs checking.
- `literature_notes.md` has the short paper notes I want available during the meeting.

The licensed form templates, project paperwork, PDFs, and private run folders are not included here. The demo uses the exported synthetic results in `surca_research_pipeline/demo/src/generated/trace-ed-data.json`.
